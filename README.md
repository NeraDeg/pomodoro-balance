# Помодоро Баланс 🌿

Android-приложение для сосредоточенной работы и отдыха: помодоро-таймер, заметки и календарь дел в атмосфере лесной сказки.

Моё первое опубликованное приложение. Создано с помощью ИИ: я придумала концепцию и оформление, направляла разработку, проверяла приложение на телефоне и довела проект до выпуска в RuStore.

**Статус:** опубликовано в RuStore · **Версия исходников:** 1.0.0 (9) · **Android:** 8.0 и выше.

## Что внутри

- Таймер фокуса с короткими и длинными перерывами, паузой и настройкой длительности.
- История занятий и связь таймера с выбранным делом.
- Заметки с папками, поиском, закреплением, списками и выбором цвета фона.
- Календарь задач, событий и дедлайнов с напоминаниями.
- Звуковые уведомления и вибрация с отдельными настройками.
- Ручной экспорт и восстановление данных в пустую установку через файл `.pmb`.

Приложение работает без аккаунта и подключения к интернету. Заметки, планы и настройки хранятся на устройстве. В оформлении — лесные звери, тёплая бумажная палитра и шрифт Montserrat.

## Как создавался проект

На этом проекте я осваиваю AI-assisted разработку на практике: формулирую задачи для ИИ, проверяю результат и возвращаюсь с конкретными исправлениями. Например, уточняла поведение таймера и перерывов, сохранение заметок, цвета карточек и звук завершения занятия.

Код создавался с помощью ИИ. Этот репозиторий показывает результат работы над приложением и служит основой для следующих изменений.

## Запуск проекта

1. Открыть корневую папку репозитория в Android Studio.
2. Использовать JDK 21 для запуска Gradle. Целевая версия JVM для кода — 17.
3. Установить Android SDK API 36.1 и Build Tools 36.1.0.
4. Дождаться синхронизации Gradle и запустить модуль `app` на устройстве или эмуляторе с Android 8.0+.

Путь к локальному Android SDK настраивается на вашем компьютере; `local.properties` не включён в репозиторий.

Сборка и локальные проверки из корня проекта:

```powershell
# Windows PowerShell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

```bash
# macOS / Linux
chmod +x gradlew
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Проверки на подключённом устройстве или эмуляторе:

```powershell
.\gradlew.bat connectedDebugAndroidTest
```

Эти команды приведены для воспроизведения проверок; они не означают, что тесты выполнены в текущем окружении. При подготовке этой копии репозитория Android-сборка и тесты заново не запускались.

## Данные и разрешения

Доступ к уведомлениям и точным будильникам нужен для напоминаний и завершения таймера. Поведение уведомлений также зависит от разрешений, настроек каналов и ограничений конкретного устройства.

Файл `.pmb` содержит пользовательские записи без шифрования; восстановление предусмотрено для пустой установки. Автоматической облачной синхронизации нет.
