# Ресурсы приложения

## Иллюстрации и значки

По документации исходного проекта лесные иллюстрации созданы с помощью генерации изображений, а векторные элементы интерфейса подготовлены отдельно. В репозитории сохранены ресурсы, которые используются приложением.

## Шрифт

Montserrat. Уведомление об авторских правах и текст SIL Open Font License 1.1 находятся в [OFL.txt](../app/src/main/assets/licenses/OFL.txt).

## Звук

Для мягкого сигнала таймера использована обработанная запись «Blackbird singing in garden with rustling trees in background», Cinetony, Freesound №565058. Источник и лицензия CC0 1.0 указаны в [BLACKBIRD.txt](../app/src/main/assets/licenses/BLACKBIRD.txt).

Исходная запись: https://freesound.org/people/Cinetony/sounds/565058/.

В ресурсах также сохранён предыдущий звуковой сигнал, используемый для совместимости с ранее созданными каналами уведомлений.
